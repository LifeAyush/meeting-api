Manual checks (prefer scripts/demo.py for the happy path):

1. Start the API:
   uvicorn app.main:app --reload

2. Create a meeting:
   curl -s -X POST http://localhost:8000/api/v1/meetings/ \
     -H 'Content-Type: application/json' \
     -d '{"title":"Manual check"}'

3. Upload a WAV over the WebSocket:
   python testing/websocket_audio_chunk_upload_check.py <meeting_id> fixtures/demo.wav

4. List transcripts / summarize:
   curl -s http://localhost:8000/api/v1/transcripts/<meeting_id>
   curl -s -X POST http://localhost:8000/api/v1/summary/<meeting_id>

Or run the one-shot demo against a running server:
   python scripts/demo.py
